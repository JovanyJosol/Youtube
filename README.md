# YouTube Installer

A Windows installer project for **YouTube**, created with **Actual Installer**.

## 📺 About

YouTube Installer provides a simple Classic Wizard installation experience for the YouTube application.

## ✨ Features

* Easy Windows installation
* Classic Wizard interface
* YouTube Start Menu program group
* YouTube shortcut
* Custom YouTube icon
* License Agreement
* README information
* Uninstaller support
* Option to close the running application during installation
* Product information and versioning

## 📦 Installation

1. Download the installer from the **Releases** section.
2. Run the installer.
3. Read and accept the License Agreement.
4. Follow the installation wizard.
5. Launch **YouTube** from the Start Menu or desktop shortcut.
